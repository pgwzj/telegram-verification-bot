# Telegram Verification Bot

Учебный Telegram-бот на Python 3. Команда `/code` выдаёт шестизначный код на пять минут. Отправь код в тот же личный чат, чтобы подтвердить его. После трёх неверных шестизначных кодов нужно запросить новый.

## Запуск в PowerShell

Создай бота командой `/newbot` у [@BotFather](https://t.me/BotFather). Укажи полученный токен в переменной окружения и запусти бота из папки проекта.

```powershell
$env:BOT_TOKEN = "твой_токен"
py bot.py
```

Если команда `py` недоступна, попробуй `python bot.py`. Дополнительные библиотеки не нужны. Коды хранятся в памяти и сбрасываются при перезапуске. Бот демонстрирует проверку внутри чата. Для входа на сайте понадобится интеграция с сессией сайта.
